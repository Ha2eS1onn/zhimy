# 知脉 · 项目声明

> 更新：2026-11-06 ｜ 适用：线上 Demo <https://zhimy.kasho.fun> 与仓库代码
>
> 本文是项目的正式边界说明。产品细节见 [README](../README.md)，进度与交接见 [HANDOFF](HANDOFF.md)，部署见 [DEPLOY](DEPLOY.md)。

## 1. 定位

- 个人开源、MIT、非商业项目；目标是验证「AI 答疑 → 收编 → 归位 → 复习 → 迁移」的个人知识图谱闭环，并展示工程质量。
- 线上 Demo 仅用于技术展示与体验，不以用户量、商业化或 SLA 为目标。
- 不提供付费、广告、订阅、多租户或班级共享；本项目不训练自有模型，也不使用用户数据做广告画像。

## 2. 功能边界（2026-11-06 冻结）

**已实现并维护：**

- 对话与收编、3D 知识图谱、节点讲解、关系编辑
- 复习闭环（`/review`、SM-2 简化调度、掌握度）
- JSON 导出 / 导入、示例图谱、清空数据
- 匿名账号 + 邮箱绑定、BYOK 模型、向量命中（配置 Key 时）

**明确不做（不再排期）：**

- 分享只读链接、图谱长图导出
- Realtime 跨端同步
- 应用内账号删除（数据删除方式见 §5）
- 移动端专用编辑壳、3D WebGL 升级、500 节点性能专项
- 商业化、多租户、班级 / 协作共享、VPS / 备案 / 监控告警

原因：个人非商业 Demo 的功能已足够验证核心闭环；继续扩展的收益递减，而维护成本与合规风险上升。

## 3. 数据与隐私

- 账号与图谱数据存储在项目维护者配置的 Supabase 项目中；所有表启用 RLS，只能读写自己的行。
- 匿名账号默认只有随机 user id，不要求手机号 / 真实姓名；绑定邮箱后用于跨设备登录。
- 模型 API Key 只存浏览器 `localStorage`，不上传、不入库、不导出、不写日志；请求经本项目代理转发到用户自己配置的服务商，服务商的数据处理遵循其政策。
- 拍题原图只在当次请求中发给模型服务商，不写入 Supabase；聊天缩略图存本机 IndexedDB（未加密），换设备 / 清缓存后丢失。
- 埋点事件只记录事件名与少量标量属性（最多 12 个键），不记录问题、答案、图片内容或 Key。
- 向量生成会把节点标题 / 摘要发给用户配置的 embedding 服务商；费用由用户自己的 Key 承担。
- 演示模式（`NEXT_PUBLIC_DEMO_MODE=1`）使用内存数据，刷新即重置。

## 4. AI 内容免责

- 对话、抽取、讲解、关系建议由用户配置的第三方模型生成，可能错误、过时或不完整；不构成教学、医疗、法律或其他专业建议。
- 用户应自行核对重要内容；收编、关系写入、讲解保存都需要用户确认，但确认不等于内容正确。
- 模型服务商的可用性、内容政策与计费由服务商决定，本项目不控制。

## 5. 删除数据

- 应用内提供「清空我的图谱」「清空对话记录」，会删除对应内容但保留账号。
- **当前不提供应用内账号删除**。如需彻底删除账号与数据：在 Supabase Dashboard → Authentication 删除该用户；数据库外键 `on delete cascade` 会清理 `nodes` / `relations` / `sources` / `conversations` / `chat_messages` / `events` / `review_state` 等关联数据。线上 Demo 的匿名账号也可联系维护者协助。
- 删除不可撤销；建议先「设置 → 数据 → 导出 JSON 备份」。

## 6. 未成年人 / 教育场景

- 当前是技术 Demo，不面向真实学生运营。
- 若要把本项目用于课堂、未成年人或公开教育服务，至少需要补充：监护人 / 学校告知、隐私政策、内容安全策略、数据删除与导出能力、服务商合规评估。这些不在当前范围内。

## 7. 可用性与数据持久性

- 线上 Demo 使用 Vercel Hobby + Supabase 免费项目，不承诺 SLA、可用性、数据持久性或备份。
- 免费项目可能因 7 天不活跃暂停（已配置 keepalive）；维护者可能清理 Demo 数据或重建项目。
- 中国大陆访问可能较慢；重要数据请自行导出备份。
